# API Contract Matrix — Phase Frontend 1

Source-of-truth priority used throughout this document: **1) [internal/api/server.go](../internal/api/server.go) and handler files (compiled/runtime truth) → 2) [api/openapi.yaml](../api/openapi.yaml) → 3) [ARCHITECTURE.md](../ARCHITECTURE.md) / docs/ → 4) CLAUDE_FRONTEND_PROMPTS.md**.
Every row below is evidence-linked to a `file:line`. Any row marked **GAP** has a full write-up in [API_GAPS.md](./API_GAPS.md).

Backend was **not reachable** during this audit: `curl http://localhost:8081/{,health,ready,api/v1/meta/locales}` all returned connection failures (`000`), and `docker ps` showed no running containers. All contract facts below come from static source reading only — none are live-verified. This must be re-verified against a running instance before Phase Frontend 2 implementation starts.

Legend: **CSRF** = `X-CSRF-Token` header required (via `requireCSRF` middleware). **Idem** = `Idempotency-Key` header read by the handler. Roles are the literal `requireRoles(...)` arguments — VIEWER never appears on a mutating route in the current code.

**OAuth flow (GAP-01, expanded):** this is Google Drive **file-picker OAuth**, not application login. `connect` returns a Google `authorization_url` with PKCE; the BFF/browser must open it (popup or redirect), Google redirects the user's browser to `GET /api/v1/google-drive/callback?state&code` **carrying the admin's existing session cookie**, and that endpoint both authenticates the OAuth code server-side and returns JSON (not a redirect) — see [drive/service.go:154-228](../internal/drive/service.go#L154-L228). A popup flow is viable only if the popup shares cookies with the app origin; a plain top-level redirect is safer to implement in Phase 2. `GOOGLE_OAUTH_*` must all be configured together or every Drive route degrades to `DRIVE_NOT_CONFIGURED` ([config.go:445-473](../internal/config/config.go#L445-L473)).
